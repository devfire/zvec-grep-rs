# Wire-code registry for the zg-server daemon (M1).
#
# Every line is a bare daemon code produced by `DaemonError::code()`.
# `tests/daemon_error_codes_golden.rs` renders the same set from live
# values and fails on any drift: adding an error variant without updating
# this file fails the build.
#
# Scope note: daemon codes are bare (`INDEX_MISSING`, not
# `ZVEC_GREP.ENGINE.*`-prefixed) because the TS wire carries them raw in
# job snapshots and MCP payloads. `ADDRESS_IN_USE`, `UNKNOWN_JOB`,
# `ALREADY_RUNNING`, and `SHUTDOWN_FAILED` are Rust additions (TS throws
# plain `Error`s there); the rest mirror `daemon/errors.ts` call sites.
