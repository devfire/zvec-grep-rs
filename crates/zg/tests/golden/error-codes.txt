# Wire-code registry for the zg CLI (M1).
#
# Every line is a `ZVEC_GREP.ENGINE.CLI.*` code produced by
# `CliError::own_code()`. `src/error.rs` renders the same set from live
# values and fails on any drift: adding a CLI error variant without
# updating this file fails the build.
#
# Scope note: the TypeScript CLI throws plain `Error`s with no codes, so
# every entry here is a Rust addition; the user-facing *messages* stay
# byte-identical to TS where frozen. Wrapped engine/daemon failures keep
# their own codes and are covered by the zg-core/zg-server registries.
