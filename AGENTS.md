# Project instructions
- always activate the project via serena mcp
- use serena mcp for all targeted reads and writes
- when writing new rust code, ensure `rust-advanced-patterns` and `rust-defensive-programming` skills are used
- keep new code to 500 LOCs or less per file
# - upon completion, make sure to run `cargo clippy --workspace --all-targets -- -Dclippy::pedantic`
- commit your work once done
- IMPORTANT: avoid using serena when working with multiple worktrees because it causes write conflicts
